# York Develops Blog — Agent Rules

## Publishing Workflow

After adding any new blog post (creating the `.md` file and updating `registry.json`), always:

1. Stage all changes: `git add -A`
2. Commit with a descriptive message
3. Push to the remote: `git push origin master`

Do this automatically without waiting to be asked. The site is hosted on GitHub Pages at https://yorkdevelops.com/york-develops-blog/ and will not reflect changes until they are pushed.
